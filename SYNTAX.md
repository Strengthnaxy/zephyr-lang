## 1. Общее

Zephyr — статически типизированный системный язык. Каждая переменная и функция имеют явный тип. Язык транспилируется в C++17, поэтому итоговая программа работает с нативной производительностью.

- Расширение файлов: `.zph`
- Точка входа: `fn main() -> i32`
- Разделитель операторов: `;`
- Разделитель блоков: `{ ... }`

## 3. Типы
Тип	Описание	C++ эквивалент
i32	32-битное знаковое целое	int32_t
i64	64-битное знаковое целое	int64_t
f64	64-битное число с плавающей точкой	double
bool	Логический тип	bool
string	UTF-8 строка	std::string
void	Отсутствие значения	void

Тип указывается после имени через двоеточие:
zephyr

let count: i32 = 42;
let name: string = "Zephyr";
let pi: f64 = 3.14;
let flag: bool = true;

## 4. Переменные

## 4.1. let — неизменяемая привязка
zephyr

let x: i32 = 10;
// x = 20; // Ошибка: x нельзя изменить

## 4.2. var — изменяемая привязка
zephyr

var y: i32 = 10;
y = 20; // Допустимо

## 4.3. Правила

    Тип обязателен.

    Начальное значение обязательно.

    Имя: буквы, цифры, _, начинается с буквы или _.

    Область видимости — блок { ... }.
## 5. Функции
## 5.1. Объявление
zephyr

fn имя(параметры) -> ТипВозврата {
    // тело
    return значение;
}

## 5.2. Без параметров
zephyr

fn main() -> i32 {
    print("Hello");
    return 0;
}

## 5.3. С параметрами (планируется)
zephyr

fn add(a: i32, b: i32) -> i32 {
    return a + b;
}

Примечание: в версии 0.1.0 парсер читает параметры, но кодогенератор их не поддерживает. Используйте функции без параметров.

## 5.4. Возврат

    return выражение; — вернуть значение.

    return; — вернуть void.

    Тип возвращаемого значения должен совпадать с объявленным.

## 6. Операторы

## 6.2. Арифметические
Оператор	Описание	Статус в 0.1.0
+	Сложение	Поддерживается
-	Вычитание	Лексер распознаёт, кодоген нет
*	Умножение	Лексер распознаёт, кодоген нет
/	Деление	Лексер распознаёт, кодоген нет

## 6.3. Сравнения

Лексер распознаёт ==, !=, <, >, <=, >=, но кодогенератор пока не поддерживает их в выражениях.

## 6.4. Логические

&&, ||, ! — планируются.

## 7. Выражения

## 7.1. Литералы
zephyr

42          // целое число

"текст"     // строка
true        // логическое

## 7.2. Переменные
zephyr

## 7.3. Бинарные выражения
zephyr

В 0.1.0 поддерживается только +. Остальные операторы распознаются лексером, но не генерируются.

## 8. Встроенные функции

## 8.1. print

Выводит значение в stdout с переводом строки.
zephyr

print("Hello world");
print(42);

В C++ превращается в:
cpp

std::cout << "Hello world" << std::endl;

## 9. Блоки и область видимости

Блок — это { ... }. Переменные, объявленные внутри блока, видны только внутри него.
zephyr

fn main() -> i32 {
    let a: i32 = 1;
    {
        let b: i32 = 2;
        print(a); // OK
        print(b); // OK
    }
    // print(b); // Ошибка: b не видна здесь
    return 0;
}

## 10. Примеры

## 10.1. Hello world
zephyr

fn main() -> i32 {
    let msg: string = "Hello world";
    print(msg);
    return 0;
}

## 10.2. Числа
zephyr

fn main() -> i32 {
    let a: i32 = 10;
    let b: i32 = 20;

    print(sum);
    return 0;
}

## 10.3. Несколько функций
zephyr

fn greet() -> void {
    print("Hello");
}

fn main() -> i32 {
    greet();
    return 0;
}

## 10.4. Изменяемая переменная
zephyr

fn main() -> i32 {
    var count: i32 = 0;
    count = 5;
    print(count);
    return 0;
}

## 11. Ограничения версии 0.1.0

## 11.1. Что работает

    Чтение .zph файлов.

    Разбор функций без параметров.

    Разбор let, var, return, print.

    Генерация C++17.

    Компиляция через g++.

    Сложение +.
## 11.2. Что не работает

    Функции с параметрами (парсер читает, кодоген игнорирует).

    Арифметика кроме +.

    Сравнения в выражениях.

    Условия (if, else).

    Циклы (while, for).

    Структуры, массивы, указатели.

    Проверка типов.

    Модули и импорты.
## 12. Соглашения об именовании

    Переменные: snake_case (user_name, total_count).

    Функции: snake_case (compute_sum, print_message).

    Типы: PascalCase (MyStruct, UserData) — когда появятся структуры.
