# Changelog

## [0.2.0] - 2026-10-31

### Added
- Ruby compiler (`ruby/`): lexer, parser, type checker, C++17 codegen.
- Functions with parameters.
- Arithmetic: `+`, `-`, `*`, `/`.
- Comparisons: `==`, `!=`, `<`, `>`, `<=`, `>=`.
- Logic: `&&`, `||`.
- `if`/`else`, `while`.
- Basic type checking.
- Skeletons for Zig, Rust, OCaml expression parsers.
- C++ runtime (`cpp/runtime.hpp`).
- PHP landing page (`php/index.php`).

### Changed
- `VERSION` bumped to 0.2.0.
