# Zephyr (beta)

**Ветка:** `v0.2.1-beta`
**Статус:** экспериментальная
**Стабильная версия:** [`main`](https://github.com/Strengthnaxy/zephyr-lang/tree/main)

Это бета-ветка проекта Zephyr. Здесь компилятор переписывается на **Ruby** как основной язык, с экспериментальными реализациями парсера выражений на **Zig**, **Rust** и **OCaml**.

## Что в этой ветке

- `ruby/` — основной компилятор (лексер, парсер, кодогенератор, AST, CLI).
- `zig/` — парсер арифметических выражений (3 файла).
- `rust/` — парсер арифметических выражений (5 файлов).
- `ocaml/` — парсер арифметических выражений (5 файлов, dune).

## Чего в этой ветке нет

- Готового бинарника компилятора.
- Полной проверки типов.
- Структур, массивов, указателей.
- Модулей и импортов.

## Запуск Ruby-компилятора

```bash
cd ruby
bundle install
ruby main.rb ../hello.zph -o hello
./hello
